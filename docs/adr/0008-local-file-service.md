# 0008. 로컬 file 서비스
- 상태: 승인
- 날짜: 2026-10-16

## 맥락
상품, 리뷰, 클레임 이미지를 저장해야 한다. 비용 0 제약으로 클라우드 객체 저장소를 쓸 수 없다.

## 결정
- `file` 서비스가 업로드를 받아 로컬 볼륨에 저장하고, 썸네일을 만들고, gateway를 통해 제공한다.
- 저장 위치는 `StoragePort`로 추상화한다.
- 업로드는 `TEMP`로 시작하고, 소유 서비스의 이벤트를 받아 `ATTACHED`가 된다. 오래된 `TEMP`는 정리한다.

## 결과
- 좋아지는 점: 비용 없이 실제와 같은 업로드·첨부·정리 흐름을 구현한다. 파일 첨부 확정도 이벤트 기반이라 다른 서비스와 결합하지 않는다.
- 감수하는 점: 인스턴스를 여러 개로 늘리면 공유 볼륨이 필요하다. CDN이 없으므로 캐시 헤더로 보완한다.

## 검토한 대안
- 로컬 MinIO(S3 호환): 실제 API에 더 가깝지만 컨테이너가 하나 늘어난다. `StoragePort` 뒤에서 나중에 바꿀 수 있다.
